# M3D-4 source evaluation and rights boundary — 2026-10-19

Release 10 uses only selected USDA Foundation Foods records, selected Wikidata structured entity revisions, and separately authored Tarif Atlası labels. Availability on a website did not by itself authorize copying. No product images, recipe text, nutrient values, density, allergen assertions or ABV values were imported.

The 24 pinned Wikidata revisions include deferred and rejected identities as evidence of screening, not approval. The two new source/version pairs are `usda-foundation-m3d4/2026-04-30-selection-1` and `wikidata-m3d4/entity-revisions-2026-10-19-1`; project labels use `recipeatlas-curation-m3d4/production-7`. Each has distinct checked evidence bytes. Reusing one of these labels with different bytes must fail `CATALOG_SOURCE_CHANGED` transactionally.

Every ACCEPT/EXISTING/DEFER/REJECT decision and reason is in `catalog/preparation/m3d4/candidates.json`. The 29 earlier Release-9 deferrals and seven historical review issues retain their earlier status; this release did not silently resolve them. Candidate translations were editorially screened, not independently human-approved.
