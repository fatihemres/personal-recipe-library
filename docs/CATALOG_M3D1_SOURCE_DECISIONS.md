# M3D-1 source and license decisions

Reviewed 2026-10-13 for a distributable, offline **identity-only** seed. Source descriptors and identifiers are evidence; Turkish/English culinary labels and classifications are project curation, not upstream translations. Unknown nutrition, density, allergen, and ABV metadata remain absent. No images are bundled.

| Source | Scope / identifier / language / access | Rights and offline decision |
| --- | --- | --- |
| [USDA FoodData Central SR Legacy](https://fdc.nal.usda.gov/download-datasets/) | Final April 2018 CSV archive, `fdc_id`, English food descriptions; [API guide](https://fdc.nal.usda.gov/api-guide/) also describes access, but build uses the pinned archive SHA-256 `b80817294b8850530aaedf2e515c02593b1824f763a0ff356e5c2081643e6fd0`. | USDA FDC data are [CC0 / public domain](https://fdc.nal.usda.gov/api-guide/#licensing); attribution requested. Commercial redistribution of selected factual descriptors is permitted. Approved for selected generic identities only; no branded-product bulk import, nutrients, or images. Existing snapshot and newly selected snapshot remain separately immutable. |
| [FoodOn](https://github.com/FoodOntology/foodon) | Food ontology identifiers, multilingual labels vary, OWL/RDF via repository releases. | [CC BY 4.0](https://github.com/FoodOntology/foodon/blob/master/LICENSE.txt) requires attribution and change notices; imported ontology dependencies need their own license review. No release/artifact pinned for this batch; excluded pending term-level provenance and consumer taxonomy mapping. |
| [Open Food Facts](https://world.openfoodfacts.org/data) | Barcode-oriented multilingual products; database exports and API. | [ODbL database, DbCL contents, separate image rights](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/tutorials/license-be-on-the-legal-side/). Combined-seed derivative database/share-alike obligations remain unresolved; branded products are a poor generic identity source. Excluded. API access alone is not redistribution clearance. |
| [TheCocktailDB](https://www.thecocktaildb.com/api.php) | Cocktail/ingredient API, mostly English; API identifiers/terms do not establish a curated generic source snapshot. | [Terms](https://www.thecocktaildb.com/terms_of_use.php) do not provide a sufficiently clear blanket right to bundle the full data as a commercial offline ingredient seed. Excluded pending explicit rights. |
| Project curation | English/Turkish culinary labels and category choices, keyed to the approved USDA descriptor. | Project-authored CC0 seed metadata, attributed separately from USDA. Translation is editorial, not independent expert validation. Ambiguous terms are held for review and not silently approved. |

Additional candidates (newer FDC Foundation, regional official registers and beverage references) require a pinned artifact, license and redistribution assessment before inclusion. This release does not merge an additional third-party database.
